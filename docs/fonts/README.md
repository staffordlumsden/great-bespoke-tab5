# Website PixelFonts

The site uses `pixel-thin.woff2` (11×5 Thin) and `pixel-semibold.woff2`
(13×7 Semibold). They were generated for the Great Bespoke CYD website from the
pinned mcer12/PixelFonts sources at commit
`344a6cfcd660b8546258485befb7576a47790d7d` using the generator retained in
`great-bespoke-cyd` at `projects/file-server/tools/generate_web_fonts.py`.
