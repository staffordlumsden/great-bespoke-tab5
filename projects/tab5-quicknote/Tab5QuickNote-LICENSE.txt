# Tab5 QuickNote 0.1.0 — notices and third-party attribution

Tab5 port of the Great Bespoke CYD Quicknote Micro firmware for the M5Stack Tab5
(ESP32-P4 revision v1.3 with ST7121 display and SD launcher).

Notes are written in Markdown format and appended as timestamped entries to
daily files under `/files/QuickNote/Daily/YYYY-MM-DD.md` on the SD card.
The editor features terminal-style typography using the Tab5 Terminal Mono face
(SIL OFL 1.1) in 8pt, 10pt and 15pt sizes, with surrounding UI chrome in the
Great Bespoke Tab5 console style using PixelFonts (MIT).
